# 🎓 College Voice Chatbot

Streamlit college assistant with Gemini AI, SQLite student login, FAQs, timetable, voice input, text-to-speech, and multilingual support.

## Run
1. `pip install -r requirements.txt`
2. Install FFmpeg.
3. Set `GEMINI_API_KEY` as an environment variable.
4. Run `streamlit run app.py`

Demo login in the included database:
- Username: `student01`
- Password: `student123`

The API key from the supplied code is not stored in the ZIP. If it was a real key, rotate/revoke it and use an environment variable instead.
