## Replace the project
1. Stop Streamlit (Control-C) and back up your current project folder.
2. Extract this ZIP into your project folder, replacing files.
3. Keep your existing `.env`, `.venv`, and `students.db` (do not replace your database).
4. Install: `./.venv/bin/python -m pip install -r requirements.txt`
5. Run: `./.venv/bin/python -m streamlit run app.py`

Phase 16 adds the polished, clickable PagePilot card in the sidebar.
